# Fandy Ahmad — Portfolio

Portfolio pribadi statis untuk Fandy Ahmad, mahasiswa Teknik Informatika UIN Syarif Hidayatullah Jakarta.

## Menjalankan lokal

Karena situs ini menggunakan HTML, CSS, dan JavaScript tanpa dependensi build, buka `index.html` langsung di browser atau jalankan server statis apa pun dari root repository.

## Deploy

Workflow `.github/workflows/deploy-pages.yml` otomatis mendeploy isi repository ke GitHub Pages setiap ada push ke branch `main`. Pada pengaturan repository, pilih **GitHub Actions** sebagai sumber Pages.
